# Ограничения VECTOR PDF 0.3.0

## Редактирование PDF

- Редактируется только поддерживаемый срез: изолированный `Tj` с явным `Tm`,
  один show-оператор, проверяемый встроенный шрифт (simple TrueType/Type0
  Identity-H). `TJ`, `Td/TD/T*`, `'`/`"`, вертикальный текст, Type3, Form
  XObject и нестандартные кодировки остаются read-only; причина показывается в
  панели свойств.
- Текст внутри clipping path теперь редактируется с предупреждением. Нативная
  равнодлинная замена остаётся в исходном clip; перемещённая/переформатированная
  копия добавляется на верхний слой страницы вне исходного clip. Это может
  сделать видимым текст, который исходно был обрезан, и может перекрыть
  элементы, которые были выше него. Предпросмотр показывает тот же верхний
  слой.
- Перемещённый/переформатированный текст всегда получает явный цвет исходной
  надписи (или выбранный пользователем). Если цветовое пространство не
  DeviceGray/RGB/CMYK или графика использует `gs`/нестандартный render mode,
  объект остаётся read-only.
- Замена шрифтом возможна только при наличии реальных глифов в embedded
  subset. Если проверить программу шрифта нельзя, используется встроенный
  fallback (DejaVu/osifont); метрики и начертание могут отличаться от исходного
  ГОСТ-шрифта.
- Строка, разбитая на несколько `Tj`, заменяется одним блоком. Соседние
  ячейки с большим пробелом больше не сливаются, но эвристика пробела не
  заменяет ручное выделение фрагментов.
- Form XObjects, OCG-слои и векторный текст в кривых не редактируются. Они
  отображаются PDFium и остаются нетронутыми.
- Шифрованные PDF и PDF с настоящей цифровой подписью доступны только для
  просмотра. Байтовое сохранение копии без правок разрешено. Пустые поля
  подписи и пустой `/Perms` больше не блокируют правку.

## Сохранение и производительность

- Сохранение всегда создаёт новую копию. Исходный файл не перезаписывается.
  Существующая цель сохраняется как `.bak`; имя без `.pdf` получает
  дополнение `.pdf`.
- Перед заменой выполняется структурная проверка, проверка геометрии,
  нетронутых потоков, подписей и извлечения текста PDFium. Полный QPDF
  syntax check выполняется для небольших документов; на очень больших CAD-
  потоках он ограничен по бюджету, чтобы сохранение не занимало десятки
  секунд. QA отдельно прогоняет полный QPDF/raster на реальном 18 МБ чертеже.
- Первый тайл после правки требует перезагрузки PDFium и может занимать
  сотни миллисекунд; цель 100 мс на тяжёлом листе не достигнута. Полный
  object-level/incremental save не входит в 0.3.
- Undo/Redo хранит состояния в памяти без жёсткого лимита; индексы страниц
  также не ограничены. Кеш тайлов имеет общий бюджет 256 МиБ, миниатюры —
  ограниченный LRU на вкладку. Длительная работа с десятками вкладок требует
  отдельного soak-теста.
- PDFium/QPDF/fontTools работают в процессе приложения, без sandbox и жёстких
  таймаутов. Враждебный PDF может вызвать зависание/исчерпание ресурсов;
  модель угроз описана в `SECURITY.md`.

## Обновления и платформа

- Автоматическая установка обновлений выключена по умолчанию. Обновление
  принимается только с подписанным manifest, полным набором файлов, health-
  check и readiness handshake. При сбое выполняется rollback, доступны
  `--safe-mode` и `--reset-update`.
- В репозитории намеренно оставлен placeholder публичного ключа. Пока владелец
  не установит production-ключ, обновления fail-closed. Приватный ключ в
  репозиторий не входит.
- Authenticode-подпись EXE зависит от сертификата проекта. В текущем окружении
  сертификата нет, поэтому локальная сборка **не подписана**; CI подписывает
  только при наличии секрета. SmartScreen может предупреждать.
- Локальная сборка использует bootstrap `VectorPDF.exe` 0.2.1; исходник нового
  лаунчера, PE-манифест и version resource добавлены, но MSVC в этом окружении
  отсутствует. Компиляция лаунчера — **NOT RUN**; CI-конфигурация проверяет
  `/GS`, VERSIONINFO и `longPathAware`.
- Портативный режим настроек не реализован: `QSettings` пишет в профиль
  Windows, импортированные шрифты/обновления — в `%LOCALAPPDATA%\VectorPDF`.
  Перенос папки не переносит настройки.
- Физическая приёмка Windows 11 на 100/125/150/200%, 1366×768 и 4K не
  выполнена. Offscreen Qt-тесты проверяют логику, минимальный размер 780×480,
  scrollable-панели и HiDPI-независимые метрики, но не заменяют монитор.
- Реальный чертёж Inventor 2023 (9 листов, 18 МБ) использован только локально
  для приёмки; в репозиторий он не входит. Проверки на других CAD-файлах,
  длительный soak, антивирус/OneDrive и fuzzing native-парсеров не проводились.

## Документация и лицензии

- Qt third-party notices и LGPL source offer добавлены в `licenses/`; это
  техническая, а не юридическая консультация. Полный бинарный SBOM генерируется
  в `sbom.json` при сборке.
- osifont распространяется по LGPL-3.0/GPL с font exception; уведомление и
  ссылки добавлены. Шрифты DejaVu/Orbita — по соответствующим лицензиям.
- Локализация покрывает основные подписи RU/EN; часть tooltips/ошибок и
  стандартных Qt-диалогов может оставаться на английском. Accessibility names
  и screen-reader приёмка не завершены.
