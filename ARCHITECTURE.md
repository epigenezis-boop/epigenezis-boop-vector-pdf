# Архитектура VECTOR PDF

Вместо C++-обвязки использованы PySide6 и штатные Python-обёртки нативных библиотек. PDFium и QPDF по-прежнему выполняют интерпретацию графики, рендер и разбор PDF в нативном коде. PySide6 предоставляет Qt Widgets без браузерного процесса. Python связывает интерфейс, кеш и правку потоков. Такой стек позволил одинаково тестировать ядро в Linux и собрать переносимый комплект Windows.

| Модуль | Назначение |
| --- | --- |
| `document.py` | Источник, номер открытой версии, снимки правок, Undo/Redo и метрики |
| `render.py` | Выделенный последовательный worker PDFium, тайлы, миниатюры и LRU |
| `object_index.py` | Ленивый индекс текстовых операторов страницы и запросы прямоугольников через R-tree |
| `writer.py` | Проверка исходных байтов, локальное исправление операндов и безопасная запись копии |
| `fonts.py` | Декодирование поддерживаемых шрифтов, измерение и встраивание поднаборов DejaVu |
| `canvas.py`, `ui.py` | Управление видом, интерактивный слой, просмотр свойств, вкладки и диагностика |

## Просмотр

PDFium работает в одном выделенном потоке, включая освобождение дескрипторов. В режиме просмотра пространственный индекс не строится. Полотно запрашивает видимые тайлы размером до 512 × 512 пикселей, сначала ближайшие к центру. Масштаб растрирования дискретизирован шагом √2 с учётом DPI. До появления новых тайлов Qt показывает подходящие изображения предыдущих уровней. LRU на вкладку ограничен 128 МиБ растров. Очередь меняется при навигации, ожидающий вызов отменяется, завершившийся рендер старой версии игнорируется.

## Правка

Индекс строится по запросу на конкретном листе. R-tree хранит границы строк, собранных из близко расположенных совместимых глифов. Для каждой позиции сохранены номер потока и порядковый номер оператора, исходные байты, матрицы, шрифт и сведения о допустимости правки. Объекты внутри Form отображаются PDFium. Их правка блокируется.

Ввод меняет только слой предпросмотра Qt. При применении QPDF сверяет байтовые смещения и прежние операнды. Для равноразмерной замены в поддерживаемом шрифте меняются операнды `Tj` с сохранением позиционирования. Для другой длины, цвета, размера, положения или поворота добавляется один локальный текстовый блок, а исходные текстовые операнды выбранного объекта очищаются. Вставка остаётся в прежнем графическом контексте. Если между позициями исходной строки есть другие команды рисования, такая правка отклоняется.

После подтверждения создаётся временная версия для PDFium. Сохраняются готовые тайлы остальных областей, аннулируются только порции, пересекающие прежние и новые границы. Замена версии сбрасывает внутреннее представление страницы PDFium, поэтому первый локальный тайл после правки может стоить почти столько же, сколько холодный рендер.

## Запись

Содержимое изменённого потока копируется и правится по смещениям QPDF. Если тот же поток используется на другом листе, у другого листа остаётся ссылка на исходный объект. Для нового шрифта копируется словарь ресурсов затронутого листа. При записи QPDF работает с отключённым декодированием и перекомпрессией исходных потоков. Замена выполняется через временный файл рядом с назначением, `fsync` и `os.replace`. Исходник всегда остаётся отдельным файлом. Изменившийся на диске исходник, подписи и шифрование блокируют запись.

0.1 использует полный пересчёт контейнера PDF, включая таблицу ссылок. Инкрементальная запись потребовала бы отдельного проверяемого пути для классического xref, xref-потоков и гибридных файлов. Приоритет отдаётся побайтовой проверке незатронутых потоков в сохранённой копии.

## Сборка переносимого комплекта

`tools/package_windows.py` принимает embeddable ZIP CPython 3.12 x64, каталог Windows-колёс, готовый запускающий EXE и путь результата. Загрузите колёса командой:

```sh
python -m pip download --platform win_amd64 --implementation cp --python-version 3.12 --abi cp312 --only-binary=:all: -r requirements.txt -d wheels
```

В x64 Developer Command Prompt для MSVC соберите запускатель:

```bat
cl /nologo /GS- /O2 /c tools\launcher_windows.c
rc /nologo /fo launcher_windows.res tools\launcher_windows.rc
link /subsystem:windows /entry:start /nodefaultlib /out:VectorPDF.exe launcher_windows.obj launcher_windows.res kernel32.lib user32.lib shell32.lib
python tools\package_windows.py python-3.12.10-embed-amd64.zip wheels VectorPDF.exe release\VECTOR-PDF-0.2.0-win-x64.zip
```


## Обновления

На Windows приложение проверяет стабильный выпуск из закреплённого проекта GitHub. После проверки HTTPS-источника, SHA-256, путей в архиве и версии комплект атомарно устанавливается рядом с прежней версией в `%LOCALAPPDATA%/VectorPDF/updates`. Исходная переносимая папка продолжает служить точкой запуска. Проверка и скачивание идут в фоне. До переключения приложения открытые документы проходят обычное подтверждение сохранения.

Выпуски публикуются с тегом `vX.Y.Z`. Имена файлов должны быть `VECTOR-PDF-X.Y.Z-win-x64.zip` и `VECTOR-PDF-X.Y.Z-win-x64.zip.sha256`. SHA-256 проверяет целостность загрузки и привязан к доверенному выпуску GitHub. Authenticode-подпись выпуска сейчас отсутствует.
