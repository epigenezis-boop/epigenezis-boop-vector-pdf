# Результаты тестов VECTOR PDF

В основной приёмке использован пользовательский чертёж Inventor 2023 из девяти страниц. Правка выполнена в копии. Исходный чертёж хранится отдельно от репозитория и переносимого архива.

| Сценарий | Результат |
| --- | --- |
| Замена текста в штампе на первом листе A0 | **PASS**. Использован исходный встроенный ГОСТ-шрифт |
| Разбор и открытие сохранённого PDF | **PASS**. QPDF вернул пустой список синтаксических ошибок. PDFium и Poppler извлекли новый текст |
| Структура и ресурсы | **PASS**. Размеры листов, слои и ресурсы совпали. Сырые потоки всех листов совпали, кроме одного потока на первом листе. Операторы векторной графики в затронутом потоке совпали |
| Растровое сравнение | **PASS**. Девять страниц сравнены при масштабе 0,4; штамп отдельно при 4×. Изменённых пикселей за пределами области правки — 0 |
| Добавление, удаление, поворот, смещение, цвет и новый шрифт | **PASS** на синтетическом PDF с кириллицей и повторно используемыми вложенными Form XObjects |
| Безопасность записи | **PASS**. Сохранение поверх источника, подписанного или зашифрованного файла отклонялось. Существующий файл назначения пережил отклонённую операцию |
| Сквозной тест Qt | **PASS**. Открытие, тайлы, миниатюры, выделение области мышью, предпросмотр, применение, Undo/Redo, сохранение и повторное чтение |
| Переносимая сборка | **PASS** для сборки архива и проверки его содержимого. Запуск на Windows 11 остаётся ручной проверкой |
| Цель обновления 100 мс на тяжёлом листе | **FAIL**. Первый затронутый тайл после правки потребовал 395 мс в отдельном замере |

## Воспроизведение

Установите `requirements-test.txt` и выполните из корня проекта. Для независимой проверки в Poppler понадобится `pdftotext`.

```sh
export VECTOR_TEST_PDF="/absolute/path/to/drawing.pdf"
export VECTOR_TEST_STAMP='{"box":[10,20,80,35],"extract":[8,17,140,40],"old":"Исходный текст","new":"Новый текст"}'
python -m pytest -q
PYTHONPATH=. QT_QPA_PLATFORM=offscreen python tests/qt_acceptance.py
```

Исходник можно передать через переменную среды в PowerShell. Для реального окна опустите параметр `QT_QPA_PLATFORM=offscreen`. Переменная `VECTOR_SCREENSHOT_DIR` включает сохранение двух скриншотов в указанную существующую папку.

В `VECTOR_TEST_STAMP` передайте реальные границы и текст штампа. Примерные значения в блоке выше нужно заменить своими. Тестовые материалы пользователей не распространяются с проектом.

В 0.2 дополнительно проверяются перетаскивание после вращения вида, сохранение новой позиции, разделение надписи и соседней ячейки, встраивание osifont и проверка архива автообновления.
